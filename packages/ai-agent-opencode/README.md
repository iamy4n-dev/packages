# ai-agent-opencode

Installs [OpenCode](https://opencode.ai) — an open-source agentic coding CLI that supports multiple AI providers (Anthropic, OpenAI, etc.) and runs entirely in your terminal.

Requires the `node-runtime` package (nvm + Node.js LTS).
