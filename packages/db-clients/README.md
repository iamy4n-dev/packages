# db-clients

Installs terminal clients for the three most common databases in Python backend stacks.

| Tool | Purpose |
|------|---------|
| psql | PostgreSQL interactive terminal |
| redis-cli | Redis CLI client |
| mycli | MySQL/MariaDB CLI with auto-completion and syntax highlighting |
