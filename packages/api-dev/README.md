# api-dev

Installs CLI tooling for API development and testing workflows.

| Tool | Purpose |
|------|---------|
| http | HTTPie — human-friendly HTTP client |
| curl | General-purpose URL transfer tool |
| grpcurl | cURL-like CLI for gRPC services |
