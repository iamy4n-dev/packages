# k8s-tools

Installs a pinned set of Kubernetes tooling for cluster management and development workflows.

| Tool | Purpose |
|------|---------|
| kubectl | Kubernetes CLI |
| helm | Package manager for Kubernetes |
| k9s | Terminal UI for Kubernetes |
| kubectx | Switch between Kubernetes contexts |
| kubens | Switch between Kubernetes namespaces |
| kustomize | Template-free config customization for Kubernetes |
