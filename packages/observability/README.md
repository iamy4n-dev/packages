Installs CLI tooling for observability workflows.

| Tool | Purpose |
|------|---------|
| promtool | Prometheus CLI — validate rules, query metrics |
| grafana-cli | Grafana plugin and config management |
| stern | Multi-pod log tailing for Kubernetes |
