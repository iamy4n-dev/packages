# ai-agent-claude

Installs [Claude Code](https://claude.ai/code) — Anthropic's agentic coding CLI. Reads files, runs commands, and reasons across your entire codebase to complete tasks end-to-end.

Requires the `node-runtime` package (nvm + Node.js LTS).

| Tool | Purpose |
|------|---------|
| claude | Anthropic's AI coding agent |
