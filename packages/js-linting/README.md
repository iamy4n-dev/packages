# js-linting

Installs ESLint and Prettier as global CLI tools. Per-project config files (`.eslintrc`, `prettier.config.js`, plugins) are managed by each project's `package.json`.

| Tool | Purpose |
|------|---------|
| eslint | Pluggable JavaScript and TypeScript linter |
| prettier | Opinionated code formatter |
