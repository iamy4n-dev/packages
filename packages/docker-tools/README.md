# docker-tools

Installs the Docker engine, Compose plugin, and BuildKit for container build and lifecycle workflows.

| Tool | Purpose |
|------|---------|
| docker | Container runtime and CLI |
| docker-compose | Multi-container orchestration |
| buildctl | BuildKit daemon client for advanced image builds |
