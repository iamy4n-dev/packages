# cli-essentials

A coarse bundle of essential CLI tools included in every `y4n` distro.

| Tool | Purpose |
|------|---------|
| zoxide | Smarter `cd` with frecency ranking |
| eza | Modern `ls` replacement |
| fzf | Fuzzy finder for shell history and files |
| tldr | Community-maintained command cheatsheets |
| atuin | Shell history synced across machines |
| ripgrep | Fast recursive grep |
| jq | JSON processor |
| yq | YAML processor (jq for YAML) |
| bat | `cat` with syntax highlighting |
| tmux | Terminal multiplexer |
| make | Build automation |
