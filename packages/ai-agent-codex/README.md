# ai-agent-codex

Installs [OpenAI Codex CLI](https://github.com/openai/codex) — a terminal-native coding agent that reads your codebase, writes code, and executes commands under your supervision.

Requires the `node-runtime` package (nvm + Node.js LTS).

| Tool | Purpose |
|------|---------|
| codex | OpenAI's terminal coding agent |
