# registry-tools

Installs tools for working with container registries — inspecting manifests, copying images, and querying tags without pulling full images.

| Tool | Purpose |
|------|---------|
| crane | Google's tool for interacting with container registries |
| skopeo | Inspect and copy images across registries without a Docker daemon |
